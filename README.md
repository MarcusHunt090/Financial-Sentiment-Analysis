# Financial Sentiment Analysis

An overview repository for my interest in applying natural language processing to financial news and business language.

## Explore the implemented project

The application code, setup instructions, dataset notes, and model details are in **[FinSentiment (`nlp-finance`)](https://github.com/MarcusHunt090/nlp-finance)**.

FinSentiment compares classical sentiment classifiers, a stacking meta-learner, and optional FinBERT predictions. Its web interface supports article and text analysis, sentence-level breakdowns, explanations, and model evaluation.

## Related work

[Financial Headline Risk Analyzer](https://github.com/MarcusHunt090/financial-risk-analyzer-89) combines sentiment and topic classification with an interpretable, rule-based headline risk score.

This repository currently contains documentation only. Visit the linked repositories for runnable code.
